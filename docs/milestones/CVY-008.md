## 1. Objective and Definition of Done

**Objective:** The frozen RUN/ITEM state machine, driving `openRun → commitAction → item write →
sealRun` through kh-client, with every transition transactional and emitting exactly one events row.

| DoD criterion                                                                | Met? | Evidence                                                                             |
| ---------------------------------------------------------------------------- | ---- | ------------------------------------------------------------------------------------ |
| RUN machine RECEIVED→…→SEALED_OK \| SEALED_PARTIAL                           | ✅   | Live run: `SEALED_OK`; a failed earlier run: `SEALED_PARTIAL`                        |
| ITEM machine incl. DEFERRED, RETRYING, SKIPPED                               | ✅   | DEFERRED→SIMULATED observed live; SKIPPED via `planExhaustion`; RETRYING capped at 2 |
| COMMITTED requires prior SIMULATED + APPROVE                                 | ✅   | Guard returns early if `state !== 'SIMULATED'`                                       |
| SUBMITTED→LANDED requires `completed` **and** non-null hash from GET /status | ✅   | G-23 handled; a completed-without-hash goes to FAILED, never LANDED                  |
| RETRYING only on transient, capped then FAILED; config-revert no retry       | ✅   | `isTransient()`; `MAX_ONCHAIN_RETRIES = 2`                                           |
| openRun → commitAction → write → sealRun via kh-client                       | ✅   | All four observed with real hashes                                                   |
| App-side deferral gate                                                       | ✅   | `releaseDeferred()`; items 1 and 2 released as dependencies landed                   |
| Every transition transactional, one events row                               | ✅   | `$transaction` + guarded `expect` state; 21 events on the 3-item run                 |
| 3-item batch RECEIVED→SEALED_OK with real hashes                             | ✅   | §4                                                                                   |
| Invalid item VETOED at zero gas                                              | ✅   | `RootNotSet()`, SIMULATE-only attempt, `gas=0`, no txHash                            |
