# CVY-009 - SSE timeline, audit drawer, and replay

Completed 2026-08-06.

## Delivered

- `GET /api/runs/:id/stream` is a dynamic SSE route backed by a `ReadableStream`.
- The route emits `events.id` as the SSE id, accepts `Last-Event-ID`, replays only rows with
  `id > lastId` in ascending order, then tails the append-only ledger until the run is terminal.
- Terminality comes from the ledger run status, not the event name. The worker uses `RUN_SEALED`
  both for entry into `SEALING` and for the final `SEALED_OK` transition, so treating every event
  with that name as terminal would close the stream before a later `RUN_SEALED_PARTIAL` result.
- `X-Accel-Buffering: no`, no-cache headers, and a terminal stream event prevent proxy buffering and
  browser reconnect loops.
- The run page now has Timeline and Manifest tabs. Timeline rows derive their state from the event
  history and show retry chips, gas consumed, veto reasons, zero gas, and failure details.
- The audit drawer shows the stored Planner rationale, Critic/simulator evidence, all persisted
  attempts, transaction links, and the ConvoyRegistry commit transaction.
- Refresh replay is server-side from the database snapshot, so a browser refresh does not depend on
  the previous JavaScript process still holding events.

## Corrective review — 2026-08-07

Commit `8e8ea05` fixed chronological retry transitions and kept live attempt/audit state current.
A subsequent review found that `phaseSeal` emits `RUN_SEALED { phase: "sealing" }` before the
KeeperHub seal write, while the SSE route treated the name alone as terminal. The route now reads
run status before each event batch and closes only on a terminal ledger status; that ordering also
ensures the transactionally paired final event is read before the stream closes. The timeline shows
the first event as `SEALING` and the actual final event as `SEALED_OK` or `SEALED_PARTIAL`.

No architectural fallback or protocol capability was invented. The existing manifest tab remains
available, and CVY-013 owns the dependency graph and onchain gate.
