**Date:** 2026-08-04 · **Roadmap day:** D4 · **Priority:** P0 · **Effort:** 5h → ~2h

## 1. Objective and Definition of Done

**Objective:** Implement the locked database schema from `docs/ARCHITECTURE.md` §5(g) as a standalone
Prisma package with migrations and seed fixtures — Convoy's ledger of record and the third leg of the
manifest's three-way reconciliation.

| DoD criterion                                                                   | Met? | Evidence                                                                                                                           |
| ------------------------------------------------------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Five models matching the frozen schema exactly                                  | ✅   | `information_schema` returns exactly `attempts, events, items, manifests, runs` — asserted, and asserted that nothing was invented |
| `bytea`→`Bytes`, `numeric(20,6)`→`Decimal`, `jsonb`→`Json`; money never a float | ✅   | 6 money columns asserted `numeric` precision 20 scale 6; 5 bytea; 4 jsonb; `gas_used_wei` unconstrained `numeric`                  |
| `runs.run_id_onchain` unique                                                    | ✅   | `runs_run_id_onchain_key` UNIQUE index                                                                                             |
| `items` unique `(run_id, idx)`                                                  | ✅   | `items_run_id_idx_key` — **plus** a behavioural test that a duplicate insert rejects                                               |
| index `attempts(item_id, attempt_no)`                                           | ✅   | `attempts_item_id_attempt_no_idx`                                                                                                  |
| index `events(run_id, at)`                                                      | ✅   | `events_run_id_at_idx`                                                                                                             |
| `events.id` is bigserial (the SSE id)                                           | ✅   | `data_type = bigint`, `nextval('events_id_seq')`; monotonicity test                                                                |
| `events` append-only, no update/delete in the client surface                    | ✅   | Type-narrowed **and** runtime-thrown; 5 tests defeat the types with a cast                                                         |
| `runs` carries the frozen `runEthUsd`                                           | ✅   | `runs.run_eth_usd numeric(20,6)`, populated by the seed                                                                            |
| Seed inserts the 3-item and 12-item fixtures                                    | ✅   | `runs=2 items=15 events=2`                                                                                                         |
| Generated client imports cleanly in web and worker                              | ✅   | Real-import probe typechecked in both, then removed                                                                                |
