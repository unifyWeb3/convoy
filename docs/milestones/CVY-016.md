# CVY-016 — Ablation Harness and README Honesty Table

**Status:** DONE — live evidence accepted 2026-08-11

## Outcome

CVY-016 is complete. The production ablation harness ran the same 11-item fixture three times on
fresh `MockRewardDistributor` deployments on Base Sepolia (84532): the full system, Planner
ablation, and Critic ablation. All three runs used Convoy's single production lifecycle and executed
every chain write through KeeperHub.

The full system used a genuine GenLayer-backed Planner (`source=planner`, one attempt) and genuine
Critic verdicts (`criticConsulted=true`). Planner ablation disabled dependency extraction and used
input order while preserving the normal simulation/Critic gate. Critic ablation reused the exact
accepted baseline plan and deliberately bypassed the Critic gate.

The accepted result differs from the task card's illustrative wasted-gas outcome. That difference
is disclosed rather than normalized: KeeperHub rejected the two invalid Critic-ablation submissions
before target broadcast, so they are neither target-level onchain reverts nor wasted-gas events.

Planner ablation's 100% submitted-item rate is not equivalent to full-system performance: only one

the production simulation/Critic gate remained enabled.

Critic ablation submitted ten items. Eight landed; two invalid submissions were rejected by
KeeperHub during pre-broadcast processing. Those two attempts have no target transaction hash and
no receipt gas. They are reported as **two KeeperHub pre-broadcast rejections, zero target-level
onchain reverts, and zero wasted-gas events**.

## Implementation and Provider Evidence

- Baseline, Planner ablation, and Critic ablation all use the one `runBatch`/orchestrator rail.
- Metrics are calculated from final ledger items and persisted EXECUTE attempts, including
  receipt-derived gas; fixture labels do not decide what landed or failed.
- The stateless GenLayer contract is invoked behind the unchanged `LlmCaller` boundary through
  accountless `simulateWriteContract`; Convoy runtime has no GenLayer private key and submits no
  GenLayer runtime transaction.
- Planner/Critic Zod validation, repair, fallback, corroboration, and audit behavior remain intact.
- The real-role GenLayer preflight passed before the accepted runs. The baseline artifact records
  `model=genlayer/bradbury-consensus`, `source=planner`, and `attempts=1`.

## Acceptance Decision

The hard requirements are satisfied: the harness produced three real, ledger-backed Base Sepolia
runs through KeeperHub, the Planner and Critic ablations are genuine, the metrics are printed from
durable evidence, and the README maps the claim to immutable artifacts. The task card's target-level
revert and wasted-gas numbers were illustrative expected outcomes, not a separate hard submission
gate. The measured KeeperHub pre-broadcast behavior is accepted and disclosed exactly.

CVY-016 is closed. No live experiment should be rerun and none of the accepted JSON artifacts
should be regenerated or normalized.
