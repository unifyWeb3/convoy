# CVY-003 — Deploy + verify on Base + FIRST REAL BASE TRANSACTION

**Roadmap:** D2 · **Priority:** P0 · **Complexity:** M · **Risk:** **HIGH** (submission requirement)

## Objective

Deploy and Basescan-verify `ConvoyRegistry` on **Base Sepolia (84532)** per DEC-001, then land the
**first real Base transaction** — `openRun` — through KeeperHub's org Turnkey wallet via the
kh-client. This
provisionally satisfies the hackathon's hard submission requirement (a link to a transaction the
agent executed via KeeperHub) before any feature work begins.

**This is the single most important milestone in the first week. Front-loaded to Day 2 by design.**

## Files expected

```
scripts/first-tx.ts
packages/contracts/broadcast/            (generated deploy artifacts)
.env                                     (CONVOY_REGISTRY_ADDR, MOCK_DISTRIBUTOR_ADDR — local only)
README.md                                (honesty table + verified-artifacts table filled in)
docs/DEPLOYMENT.md                       (recorded addresses)
```

## Dependencies

CVY-002, plus a minimal write path from CVY-004. **Blocks:** the submission itself; unblocks the
whole KeeperHub story.

## Required inputs (must be provisioned before this milestone can run)

- `KEEPERHUB_API_KEY` — org `kh_` Bearer, with the org Turnkey wallet configured.
- `BASE_RPC_URL` — dedicated RPC, chain pinned to 84532 (Base Sepolia, DEC-001).
- `ETHERSCAN_API_KEY` — single Etherscan API **V2** key (legacy per-chain V1 keys are rejected).
- `DEPLOYER_PRIVATE_KEY` — Foundry deploy only, funded from a **Base Sepolia faucet**.
- The org wallet funded with Base Sepolia ETH. **Gas sponsorship is never load-bearing.**

## Acceptance criteria

- `ConvoyRegistry` deployed **and verified** on Basescan at chain 84532.
- `MockRewardDistributor` deployed and verified, clearly labelled in the README as a demo stand-in.
- One real `openRun` transaction landed through KeeperHub, with a real `transactionHash` and a
  working `transactionLink`.
- The transaction hash and Basescan link are recorded in the README honesty table.
- Convoy triggered the execution itself. **No private key was used at runtime** — only
  `forge script` used `DEPLOYER_PRIVATE_KEY`.

## Verification steps

**Follow [`docs/RUNBOOK_FIRST_TRANSACTION.md`](../../docs/RUNBOOK_FIRST_TRANSACTION.md).** It is the
single operational authority for this sequence; the commands are not duplicated here. Work Part 1
top to bottom, then fill Part 2 from real output.

Two debts close inside this milestone, and the runbook has a section for each:

- **D-019** (§2.5) — run the named `fund`-before-`setRoot` case against the deployed
  `MockRewardDistributor`. CVY-004 substituted WETH9 because this contract did not exist; the
  substitution does not carry forward.
- **G-20** (§2.6) — record whether `revertReason` usefully decodes a **custom** error. CVY-011's
  veto evidence depends on the answer.

## Fallbacks (in order)

1. **Base Sepolia is the target, not the de-risking step** (DEC-001). KeeperHub direct execution on
   84532 is **verified** — a live `simulate:true` returned HTTP 200 with `wouldRevert:false`, tape at
   `packages/kh-client/test/vcr/dec-001.simulate.84532.probe.json`. If a _write_ nonetheless fails on
   84532 in a way a simulate did not predict, fall back to **Base mainnet (8453)** with a
   minimal-value run, set `BASE_MAINNET_RPC_URL`, and revisit DEC-001 rather than working around it.
2. If the KeeperHub REST write is blocked, land `openRun` via the CLI:
   `kh ex cc --chain --contract --method --args --wait`.
   Note: the CLI has **no** `--simulate` and **no** `--value` (gap G-05); the ABI flag is
   `--abi-file`.
3. If no hash exists by end of Day 2, **stop all other work** until one does.

## Hard rules

- Never fabricate a transaction hash. If nothing landed, the milestone is not done.
- Never set a nonce. Ordering belongs to KeeperHub.

## Rollback

Contracts are immutable — rollback means deploying a **fresh instance** and updating
`CONVOY_REGISTRY_ADDR`. State is never migrated.

**4h.**

## Deliverables

A verified `ConvoyRegistry` on Base Sepolia, a verified demo distributor, and one real Basescan
transaction link recorded in the README — the submission requirement, provisionally met.
