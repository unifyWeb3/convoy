# CVY-012 — Manifest exporter (3-way reconcile + sha256 + export)

**Roadmap:** D10 · **Priority:** P0 · **Complexity:** M · **Risk:** Medium

## Objective

Reconcile three **independent** sources into one sha256-stamped, replayable manifest. This artifact
is the deliverable the DAO actually wants — the answer to "what did the treasury do?" that is not a
block-explorer screenshot.

## The three sources

1. **KeeperHub status** — `transactionHash`, `gasUsedWei`, status, from the direct-execution status
   endpoint plus the Keeper Runs audit trail.
2. **ConvoyRegistry events** — `RunOpened`, `ActionCommitted`, `RunSealed`, read from chain via viem
   on the pinned dedicated RPC (8453).
3. **Convoy's own ledger** — `runs`, `items`, `attempts`, `events`.

## Files expected

```
apps/web/lib/manifest.ts
apps/web/app/api/runs/[id]/manifest/route.ts
apps/web/app/runs/[id]/_components/Manifest.tsx
apps/web/test/api.manifest.export.test.ts
```

## Dependencies

CVY-008, CVY-009. **Blocks:** GATE 2, CVY-016.

## Acceptance criteria

- One reconciliation row per item, with one column per source.
- **Green when all three agree; amber when they diverge.** A divergence is surfaced, never silently
  smoothed into green — the honesty of this table is the point.
- The exported JSON is sha256-stamped and stored in `manifests`. Re-exporting an unchanged run
  produces a **stable** hash.
- The manifest discloses the `runEthUsd` used for gas→USDC accounting, so the numbers are
  reproducible.
- Export offers both a JSON download and a copy action.
- Registry reads use `BASE_RPC_URL` (pinned to 8453). **Never** `eth_getLogs` on a public RPC.
- The reconciliation is cached from the run so it renders during the demo even without a live RPC.

## Verification steps

```bash
pnpm --filter @convoy/web test
# integration: complete a run, export the manifest, confirm all rows green
# re-export and confirm the sha256 is identical
```

## Fallback

2-way reconcile (KeeperHub + Convoy ledger), **disclosed** in the honesty table. This is cut order
#5 — the last cut, not the first.

## Rollback

Revert. The run data remains in the ledger and a manifest can be re-derived later.

## Effort

**8h.**

## Deliverables

A three-way reconciliation table, a stable sha256-stamped export, and honest amber on divergence.
