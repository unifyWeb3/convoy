# CVY-007 — Budget meter + gas→USDC accounting

**Roadmap:** D4/D8 · **Priority:** P0 · **Complexity:** S · **Risk:** Low

## Objective

A USDC budget meter that drains from **real** gas spend and real payment spend, constrains the
Planner, and ends a run early rather than overspending. Every number must trace to a transaction
hash — the meter's credibility is the point.

## Pinned formula (blueprint A5 — do not vary)

```
gas_used_usdc = (Number(gasUsedWei) / 1e18) * runEthUsd
```

`gasUsedWei` is the **total fee in wei**. `runEthUsd` is frozen into the `runs` row at run open from
`CONVOY_ETH_USD`. This is deliberately not a live oracle (gap G-04) — a price feed on the reliability
path would be load-bearing external dependency. The manifest discloses the rate used.

## Dependencies

CVY-004, CVY-005. **Blocks:** CVY-008.

## Acceptance criteria

- The meter drains on every real `gasUsedWei` from the status endpoint, and on every real x402
  settlement once CVY-017 lands.
- `runEthUsd` is written to `runs` at open and never re-read from the environment mid-run.
- A `BUDGET_LOW` event fires at 20% remaining; the UI meter turns amber.
- Per-item gas allocation comes from the plan. When simulate `gasEstimate` exceeds the allocation,
  the item is `VETOED(over_budget)` **before** any spend.
- On exhaustion, remaining items become `SKIPPED` and the run seals `SEALED_PARTIAL` — it ends early
  rather than overspending.
- Money is `numeric(20,6)` / Prisma `Decimal`. Wei is `bigint`/`string`. **Never a float.**

## Verification steps

## Fallback

Gas-only budget (cut order #1 removes the x402 payment leg). Disclose the cut in the honesty table.

## Rollback

Revert. The state machine can run without a meter, but `over_budget` vetoes and `SKIPPED` are lost —
record that in `docs/KNOWN_GAPS.md` if it is ever shipped that way.

## Effort

**5h.**

## Deliverables

A budget meter whose every number traces to a real transaction hash, with the amber threshold, the
`over_budget` veto path, and early-sealing on exhaustion.
