# CVY-004 — kh-client (KeeperHub REST direct execution)

**Roadmap:** D2–D3 · **Priority:** P0 · **Complexity:** L · **Risk:** **HIGH** (external API drift)

## Objective

One typed client for **all** KeeperHub direct execution: write, simulate, status polling,
check-and-execute, error classification, and idempotency. This package is the **only** module in the
repository permitted to reach `app.keeperhub.com`. All API drift is absorbed here behind stable
types, so every other package consumes a stable contract.

## Acceptance criteria

- **Write:** `POST /api/execute/contract-call` returns `{executionId:"direct_...", status}`. The
  request sends **both** `chainId:"8453"` and `network:"8453"` (gap G-01), and `functionArgs` as a
  JSON-array **string**.
- **Simulate:** `simulate:true` (strict boolean) returns a typed
  `{wouldRevert, revertReason, gasEstimate}`. A `fund`-before-`setRoot` call must return
  `wouldRevert:true` with a decoded `revertReason`.
- **Status:** `GET /api/execute/{id}/status` returns `{status, transactionHash, transactionLink,
gasUsedWei}`. The client honours `X-Poll-Interval-Hint` (0 = terminal) and **short-circuits the
  poll** when the POST response is already terminal (gap G-02).
- **Errors:** 401 fatal · **403 daily cap fatal-to-run** · **422 wallet-not-configured fatal-to-run**
  (gap G-03) · 429 backoff honouring `Retry-After` · coded run errors `E-000x`/`N-000x`/`P-000x`/
  `C-0001-2` classified transient · **config-revert (full message, no code) = item FAILED, never
  retried.**
- **Idempotency:** every write carries `Idempotency-Key: <runId>:<idx>:<attempt>` (per-org, 24h);
  simulate calls are exempt. `409 idempotency_in_progress` → retry after backoff.
  `409 idempotency_conflict` → treat as a Convoy bug, fail the item.
- Convoy's own faults (network, timeout) retry with jittered backoff. **Onchain** retries are never
  performed by Convoy — only observed.
- Vocabulary: `contractAddress` / `functionName` / `functionArgs` / `abi`. **Never** `abiFunction`.
  **Never** `call_workflow` for a write (it returns unsigned calldata and bypasses the reliability
  stack).
- No `nonce:` appears in any payload.
- VCR mode (`CONVOY_KH_MODE=vcr`) replays recorded tapes so UI development works offline.
