# CVY-011 — Critic agent + simulate veto + corroboration

**Roadmap:** D7 · **Priority:** P0 · **Complexity:** L · **Risk:** Medium

## Objective

A **second, separately-prompted** LLM that judges each action's justification against the evidence,
grounded by an external verifier — KeeperHub's real `simulate:true` dry run. The veto costs zero
gas: the simulation runs `estimateGas` + `provider.call` with no signing, no broadcast, and no audit
row. This milestone must never be cut.

## Why a second LLM and not just the simulator

The simulator answers "does this revert now". The Critic answers "is this justified by the evidence
and the plan" — funding 2× the CSV total simulates fine but is wrong (`evidence_mismatch`). The
design follows the external-verifier literature (Gou et al., CRITIC, ICLR 2024; Huang et al., "LLMs
Cannot Self-Correct Reasoning Yet", ICLR 2024): intrinsic self-correction is unreliable without an
external tool. Convoy's external tool is the KeeperHub simulator.

## Acceptance criteria

- Per action the Critic emits APPROVE or VETO with a reason from a **closed enum**:
  `{would_revert, over_budget, unmet_dependency, evidence_mismatch}`.
- **Corroboration rule (non-negotiable):**
  - A `VETO(would_revert)` **must** be corroborated by `simulate.wouldRevert === true`.
  - A Critic APPROVE on an action the simulator says would revert is **overridden to VETO**.
  - Revert and overspend verdicts are decided by the **deterministic simulator**, not the model.
  - Any disagreement resolves to the simulator.
- `over_budget` comes from comparing the simulate `gasEstimate` against the plan's per-item
  allocation — arithmetic, not judgement.
- An unknown or non-whitelisted target is an automatic `VETO(evidence_mismatch)`.
- Maximum **one** re-plan cycle; a persistently vetoed item becomes `FAILED` and the run seals
  partial. No infinite loop.
- The Critic uses its own prompt and its own context — it is not a self-check of the Planner.

## Eval bar

- **≥4/5 invalid items vetoed.**
- **5/5 valid items passed — zero false vetoes.** A false veto wastes an epoch; this is the hard bar.

## Verification steps

```bash
pnpm tsx tests/critic.veto.eval.ts       # ≥4/5 invalid, 5/5 valid, 0 false vetoes
pnpm --filter @convoy/web test           # corroboration override test
# proof: a real simulate response body showing wouldRevert:true with a decoded revertReason
```

## Fallback

Simulator-only gate with the Critic demoted to advisory. The zero-gas veto survives; the
evidence-justification judgement is lost. Disclose it in the honesty table.

## Rollback

Revert to the simulator-only gate — never to no gate at all.

A grounded Critic with a corroboration override, a 5-valid/5-invalid fixture, and a passing eval
with zero false vetoes.
