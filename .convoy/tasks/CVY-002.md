# CVY-002 — payloadHash parity (Sol↔TS) + deploy script

**Roadmap:** D1–D2 · **Priority:** P0 · **Complexity:** M · **Risk:** **Medium** (dynamic-type packing)

## Objective

Make `payloadHash` byte-identical in Solidity and TypeScript, proven by a parity test, and have the
Foundry deploy script ready for Base Sepolia (the primary chain per DEC-001) and, optionally, Base
mainnet at CVY-019. `commitAction` correctness — the
onchain proof that item `idx` was committed with exactly this payload — depends on this parity.

## Pinned encoding (blueprint A4 — do not vary)

```
Solidity:  keccak256(abi.encode(address target, string fn, bytes args, uint256 idx))

TypeScript (viem):
  keccak256(encodeAbiParameters(
    [{type:'address'},{type:'string'},{type:'bytes'},{type:'uint256'}],
    [target, functionName, encodedArgs, BigInt(idx)]
  ))

encodedArgs = the ABI-encoded argument tuple bytes (encodeAbiParameters over the function's
input types) — NOT the 4-byte-selector calldata.
```

## Acceptance criteria

- The parity test asserts TypeScript output equals Solidity output on **≥10 fixtures**, dumped by a
  forge script (not hand-written), covering dynamic types: long function names, empty args,
  multi-arg tuples, `bytes32`, `uint256`, and address arrays.
- `Deploy.s.sol` deploys `ConvoyRegistry` and `MockRewardDistributor` and is parameterised for
  Base Sepolia (84532 — the primary chain per DEC-001) and Base mainnet (8453 — optional, CVY-019).
  Both remain in the chain allowlist; DEC-001 changes the target, not the supported set.
- `DEPLOYER_PRIVATE_KEY` is read **only** inside `packages/contracts/script`. The CI grep-guard must
  stay green.

## Documented fallback

If dynamic-type packing drifts, switch **both sides** to hashing the pieces:
`keccak256(abi.encode(target, keccak256(bytes(fn)), keccak256(args), idx))`.
Record the switch in `docs/DECISIONS.md` as a numbered decision. Do not invent a third encoding.
