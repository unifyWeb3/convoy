# CVY-005 — DB package (Prisma schema, migrations, seed)

**Roadmap:** D4 · **Priority:** P0 · **Complexity:** M · **Risk:** Medium (Decimal/Bytes mapping)

## Objective

Implement the locked database schema from `docs/ARCHITECTURE.md` §5(g) as a standalone Prisma
package, with migrations and seed fixtures. This is Convoy's ledger of record and the third leg of
the manifest's three-way reconciliation.

## Files expected

```
packages/db/prisma/schema.prisma
packages/db/prisma/migrations/
packages/db/prisma/seed.ts
packages/db/src/index.ts              (PrismaClient singleton + exported types)
packages/db/package.json              (db:generate / db:migrate / db:deploy / db:seed)
packages/db/test/{schema.migrate,seed.fixtures}.test.ts
```

## Dependencies

CVY-000. **Blocks:** CVY-006, CVY-007, CVY-008.

## Acceptance criteria

- Five models matching the frozen schema **exactly**: `runs`, `items`, `attempts`, `events`,
  `manifests`.
- Type mapping: `bytea` → Prisma `Bytes`; `numeric(20,6)` → Prisma `Decimal`; `jsonb` → `Json`.
  **Money is never a float.**
- Constraints preserved: `runs.run_id_onchain` unique; `items` unique on `(run_id, idx)`;
  index on `attempts(item_id, attempt_no)`; index on `events(run_id, at)`.
- `events.id` is `bigserial` — it is the SSE event id used for `Last-Event-ID` replay (blueprint A6).
- `events` is append-only. No update or delete path exists in the client surface.
- `runs` carries the frozen `runEthUsd` used for gas→USDC accounting.
- Seed inserts both the 3-item fixture (for CVY-008) and the 12-item fixture (for GATE 2).
- The generated client imports cleanly in both `apps/web` and `services/worker`.

## Verification steps

```bash
pnpm --filter @convoy/db db:generate
pnpm --filter @convoy/db db:migrate
pnpm --filter @convoy/db db:seed
pnpm --filter @convoy/db test
pnpm --filter @convoy/db typecheck
```

## Rollback

Migrations are **forward-only**. To roll back, write a new forward migration; never edit an applied
one. Restore from the pre-demo snapshot if a migration proves destructive.

## Effort

**5h.**

## Deliverables

A migrated Postgres schema matching the frozen design, a seeded 3-item and 12-item fixture, and a
shared Prisma client consumed by the web app and the worker.
