# CVY-000 — Repository bootstrap and toolchain

**Roadmap:** D1 · **Priority:** P0 · **Complexity:** S · **Risk:** Low

## Objective

Stand up the pnpm monorepo scaffold so that every tool in the stack runs and the empty workspace
builds, type-checks, lints, and tests clean. Establish the AI operating system (`CLAUDE.md`,
`.convoy/`), the documentation skeleton, the environment template, and the CI grep-guards that make
the reliability invariants mechanical rather than aspirational. **No protocol logic.**

## Dependencies

None. **Blocks:** every other milestone.

## Acceptance criteria

- `pnpm install` succeeds.
- `pnpm -r build` succeeds across all packages while they are still empty scaffolds.
- `pnpm -r typecheck` and `pnpm -r lint` are clean.
- `forge build` succeeds in `packages/contracts`.
- `CLAUDE.md` exists with the blueprint's exact content and is mirrored byte-for-byte to `AGENTS.md`.
- `.env.example` contains **every** variable from blueprint §11, each with a purpose comment and a
  safe example value. No real secret anywhere.
- `.convoy/` is fully populated with real content — no placeholder text.
- One task card exists for every milestone CVY-000 through CVY-019.
- `docs/KNOWN_GAPS.md` is pre-populated with G-01 … G-06.
- `scripts/bootstrap.sh` is executable and its non-secret steps run.
- `pnpm tsx scripts/verify-env.ts` prints the PASS/FAIL matrix. Checks requiring credentials that do
  not exist yet **are expected to FAIL** and must be reported honestly, never faked.
- CI workflows carry the four grep-guards: no `app.keeperhub.com` outside `packages/kh-client`;
  no `nonce:` in client/worker payloads; `PRIVATE_KEY` only under `packages/contracts/script`;
  no staged-failure patterns in non-test code.

## Verification steps

```bash
pnpm install
pnpm -r build
pnpm -r typecheck
pnpm -r lint
pnpm -r test
(cd packages/contracts && forge build)
test -x scripts/bootstrap.sh && echo "bootstrap.sh executable"
pnpm tsx scripts/verify-env.ts
diff CLAUDE.md AGENTS.md && echo "mirror ok"
bash -c 'set -e; <run the four grep-guards from .convoy/checklists/review.md>'
```

## Rollback

The bootstrap commit is the repository's first commit. To roll back, `git reset --hard` to it or
delete the generated scaffolding; the three frozen documents in `docs/` must be preserved in every
case.

## Deliverables

A monorepo that installs, builds, type-checks, lints, and tests empty; the complete `.convoy/`
operating system; the seven tracking documents; `.env.example`; the bootstrap and env-verification
scripts; and three CI workflows with mechanical invariant guards.
