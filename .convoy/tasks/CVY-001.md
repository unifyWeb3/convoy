# CVY-001 — ConvoyRegistry + MockRewardDistributor + Foundry tests

**Roadmap:** D1 · **Priority:** P0 · **Complexity:** M · **Risk:** Low

## Objective

Implement the two Solidity contracts exactly as frozen in `docs/ARCHITECTURE.md` §8, with green unit
and invariant tests. `ConvoyRegistry` is a commitment and sequencing ledger whose **storage** is
load-bearing at runtime — not an event log. `MockRewardDistributor` is the demo-only, clearly
labelled stand-in whose genuine reverts are the invalid-input source the Critic simulates against.

```
packages/contracts/src/ConvoyRegistry.sol
packages/contracts/src/MockRewardDistributor.sol
packages/contracts/test/ConvoyRegistry.t.sol
packages/contracts/test/ConvoyRegistry.invariant.t.sol

packages/contracts/foundry.toml            (optimizer, [invariant], [etherscan] sections)
```

## Dependencies

CVY-000. **Blocks:** CVY-002.

## Acceptance criteria

- `ConvoyRegistry` matches the frozen source exactly: `enum State {None, Open, Sealed}`; packed
  `Run` struct; `runs`, `payloadHash`, `committed` mappings; `RunOpened` / `ActionCommitted` /
  `RunSealed` events; the six custom errors; `openRun`, `commitAction`, `sealRun`, `isCommitted`.
  **No additions, no optimisations, no extra functions.**
- Access control is operator-bound: `msg.sender` must equal the opener.
- Custom errors only — no `require` strings.
- `MockRewardDistributor` exposes `setRoot(bytes32)`, `fund(uint256)`, `enableMarket(uint256)` and
  **genuinely reverts on unmet preconditions** (e.g. `fund` before `setRoot`).
- Unit tests cover every happy and revert path, including at minimum:
  `test_openRun_setsOpen`, `test_commitAction_revertsNotOpen`, `test_commitAction_revertsDupIndex`,
  `test_sealRun_revertsNothingCommitted`, `test_commitAction_revertsNotOperator`.
- Invariant tests via a `StdInvariant` handler: `invariant_noCommitBeforeOpen`,
  `invariant_noDoubleSeal`, `invariant_idxMonotonic`, `invariant_committedCountMatches`.
