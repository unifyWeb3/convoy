# CVY-016 — Ablation harness + README honesty table

**Roadmap:** D11 · **Priority:** P0 · **Complexity:** M · **Risk:** Low

## Objective

Prove the Planner and the Critic earn their place by measuring what happens when each is removed.
This is the single most persuasive piece of evidence a judge can verify by running one command —
and the reason the AI stays in the system at all. If ablation showed no degradation, the AI would be
removed. It does, so it stays.

## Files expected

```
scripts/ablation.ts
tests/fixtures/ablation.batch.json
README.md            (honesty table + ablation results filled in)
```

## Dependencies

CVY-010, CVY-011, CVY-012.

## Acceptance criteria

- `--ablate-planner` submits items in **input order** with no dependency extraction. Expected and
  printed: dependency-violating items hit config-reverts, wasted-gas failures rise from ~0 to the
  number of out-of-order dependencies (≥3 in the demo batch), the run ends early on budget, and the
  **landed-item rate drops from 100% to ~55% with wasted gas > 0**.
- `--ablate-critic` executes every planned item **without** the simulate gate. Expected and printed:
  the two genuinely invalid items are submitted, revert onchain and burn gas —
  **wasted-gas events go 0 → 2**, budget spent rises, and one downstream dependent item is starved.
- Both metrics are **printed by the harness**, not asserted from memory, and are pasted into the
  README honesty table.
- The ablation uses real executions against the real contracts. **No staged failure, no injected gas
  spike, no fabricated hash.** The reverts are genuine because the invalid items point at a contract
  that legitimately rejects them.
- The honesty table maps **every** reliability claim to a real artifact — a Basescan transaction, a
  simulate payload, or an export line. A claim without an artifact is removed, not softened.

## Verification steps

```bash
pnpm tsx scripts/ablation.ts                      # full system baseline
pnpm tsx scripts/ablation.ts --ablate-planner
pnpm tsx scripts/ablation.ts --ablate-critic
# paste all three outputs into the README ablation table
```

## Rollback

Revert the harness. The README honesty table must then drop the ablation claim rather than keep an
unbacked number.

## Effort

**5h.**

## Deliverables

A reproducible ablation harness, three printed metric sets, and a complete honesty table where every
claim links to a verifiable artifact.
