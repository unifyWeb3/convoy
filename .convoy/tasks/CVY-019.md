## Stretch — optional Base mainnet flip (DEC-001)

The build runs on **Base Sepolia (84532)**. Flipping the final demo run to **Base mainnet (8453)** is
optional and deliberately cheap: the chain is parameterised, `Deploy.s.sol` already allowlists 8453,
and one Etherscan V2 key covers both. **Not a submission requirement** — a Base Sepolia transaction
executed via KeeperHub satisfies the "link to a transaction the agent executed" gate.

Attempt it only if every P0 milestone is green and there is slack. Steps:

1. Set `BASE_MAINNET_RPC_URL` (it is unset by default so a stray `--rpc-url base` cannot resolve).
2. Fund the deployer and the org Turnkey wallet with real Base ETH — small amounts.
3. `forge script script/Deploy.s.sol --rpc-url base --broadcast --verify --chain base`.
4. Repoint `CONVOY_REGISTRY_ADDR` / `MOCK_DISTRIBUTOR_ADDR`, and `BASE_RPC_URL` +
   `BASE_RPC_URL_FALLBACK` at 8453 providers. `scripts/verify-env.ts` pins 84532 by design, so its
   chain row **will** go red — that is expected during a flip, not a defect. Do not edit the pin
   without amending DEC-001.
5. Re-run the demo E2E against mainnet before recording.

**Abort rule.** If the flip is not fully green with ≥4h before the deadline, revert to the Base
Sepolia run and submit that. A rehearsed testnet demo beats a rushed mainnet one, and G-18's
"real gas units, notional USD" disclosure keeps the testnet run honest. Never fabricate a hash.
