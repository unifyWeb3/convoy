# CVY-013 — DAG view + deferral + onchain check-and-execute gate

**Roadmap:** D8/D10 · **Priority:** P1 · **Complexity:** M · **Risk:** Medium

## Objective

Render the execution DAG live and add the onchain dependency gate that reads `ConvoyRegistry`
storage. This is what makes the registry's state genuinely load-bearing at runtime rather than
decorative.

## Files expected

```
apps/web/app/runs/[id]/_components/DagView.tsx
services/worker/src/gates/checkAndExecute.ts
apps/web/test/dag.render.test.tsx
```

## Dependencies

CVY-009, CVY-012.

## Acceptance criteria

- React Flow DAG coloured by item state; edges are dependencies; a deferred item's edge is **dashed
  and pulsing** until its dependency lands.
- The onchain gate uses `POST /api/execute/check-and-execute` — a documented single call that reads
  a contract value, evaluates a condition, and executes the action **only if met**, returning the
  observed value either way.
- The gate's condition reads `committed[runId][idx]` from `ConvoyRegistry`. This is the registry
  storage being read at runtime by the execution path.
- The onchain gate is an **addition to** the app-side deferral gate from CVY-008, never a
  replacement (blueprint A7). Removing it must leave deferral fully working.
- Vocabulary stays REST: `contractAddress` / `functionName` / `functionArgs` / `abi`. Never
  `abiFunction`.

## Verification steps

```bash
pnpm --filter @convoy/web test
# integration: a deferred item releases only after its dependency reaches LANDED
# proof: a check-and-execute response showing condition {met, observedValue, targetValue, operator}
```

## Fallbacks (in cut order)

- Cut #2: DAG view → an ordered list with dependency badges.
- Cut #3: onchain `check-and-execute` gate → app-side gate that still **reads the registry via RPC**.

Both cuts are disclosed in the honesty table. The deferral behaviour itself is never cut.

## Rollback

Revert. The app-side deferral gate from CVY-008 continues to work unchanged.

## Effort

**8h** (DAG) **+ 6h** (onchain gate).

## Deliverables

A live state-coloured DAG with pulsing deferral edges, and an onchain dependency gate that proves
the registry's storage is read at runtime.
