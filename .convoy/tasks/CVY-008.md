# CVY-008 — Orchestrator + RUN/ITEM state machine

**Roadmap:** D4 · **Priority:** P0 · **Complexity:** L · **Risk:** **HIGH** (core of the product)

## Objective

The state machine that ties contracts, kh-client, database, queue, and budget together, driving a
hardcoded 3-item batch from `RECEIVED` to `SEALED`. This is the spine: it blocks all run behaviour
downstream.

## Frozen state machine (`docs/ARCHITECTURE.md` §5(i))

```
RUN:  RECEIVED → OPENING → PLANNING → CRITIQUING → EXECUTING → SEALING → { SEALED_OK | SEALED_PARTIAL }
      any → ABORTED (cooperative) ; OPENING/SEALING may → FAILED_FATAL (401/422)
ITEM: PENDING → SIMULATED
        → VETOED (terminal, zero gas)
        → COMMITTED → SUBMITTED → { LANDED | RETRYING → SUBMITTED | FAILED }
        → DEFERRED → (dependency LANDED) → SIMULATED …
Terminal item states: LANDED, VETOED, FAILED, SKIPPED
```

## Acceptance criteria

- **Guards enforced:**
  - `COMMITTED` requires a prior `SIMULATED` **and** a Critic APPROVE.
  - `SUBMITTED → LANDED` requires KeeperHub status `completed` **and** a non-null `transactionHash`.
  - `RETRYING` only on a KeeperHub transient code, capped; on cap → `FAILED`.
  - A config-revert (full message, no code) → `FAILED` immediately, **never** retried.
- Run lifecycle: `openRun` → per-item `commitAction(runId, idx, payloadHash)` → the item's own write
  → `sealRun`, all through the kh-client and the org wallet.
- The EXECUTE phase treats the POST response as **possibly terminal** and short-circuits the status
  poll when it already is (gap G-02). The guard is unchanged.
- **App-side deferral gate** (blueprint A7): a `DEFERRED` item is re-evaluated on each dependency
  `LANDED`; when its `untilItem` is `LANDED`, it moves to `SIMULATED`. The onchain
  `check-and-execute` gate (CVY-013) is an **addition**, never a replacement.
- Every transition is wrapped in `prisma.$transaction` and emits **exactly one** `events` row.
- 401 → `FAILED_FATAL`. 403 (daily cap) and 422 (wallet not configured) → fatal-to-run.
  429 → backoff and resume; the run pauses, it does not fail.
- Convoy sets no nonce and holds no key anywhere in this milestone.
