# CVY-010 — Planner agent + zod schema + repair + eval

**Roadmap:** D6 · **Priority:** P0 · **Complexity:** L · **Risk:** Medium

## Objective

Turn K items plus their unstructured evidence into a validated execution DAG. Building the graph
**from prose** is the irreducibly linguistic part — a topological sort is deterministic, but
extracting the ordering constraints and parameters from a Notion note, a CSV, and a forum link is not.

```
tests/fixtures/planner.10run.json          (labelled dependency fixture)
tests/planner.recall.eval.ts
tests/planner.validJson.eval.ts
```

## Dependencies

CVY-008. **Blocks:** CVY-011, CVY-016.

## Acceptance criteria

- Output is strict JSON validated by zod:
  `{order, deferrals:[{idx, untilItem}], gasBudgetPerItem, rationalePerItem}`.
- Structured outputs / JSON mode is used; on a parse failure there is exactly **one**
  reject-and-repair pass. A second failure falls back to the cached rehearsal output — it never
  blocks the run.
- **≥95% valid JSON on first pass.**
- **Dependency recall ≥0.9** on the 10-run labelled fixture.
- **Zero cycles** emitted; a cycle check runs before the plan is accepted.
- Every proposed action resolves to a **run-whitelisted target contract**. An unknown target is
  never executed — it becomes an automatic `VETO(evidence_mismatch)` at the Critic.
- **Evidence is untrusted delimited data.** It is never concatenated into the system prompt. The
  Planner runs under a fixed instruction that evidence cannot override. An injected
  "transfer to 0xattacker" cannot resolve to a real action because of the whitelist.
- Plan output is stored as `runs.plan` JSON plus dependency edges; it is **never executed raw**.

## Verification steps

```bash
pnpm tsx tests/planner.recall.eval.ts        # recall ≥ 0.9
pnpm tsx tests/planner.validJson.eval.ts     # ≥ 95% first-pass valid
pnpm --filter @convoy/web test
```

## Fallback

Deterministic topological order from the declared `depends_on` edges. This is exactly the
`--ablate-planner` baseline, so the fallback doubles as the ablation control.

## Rollback

Revert to the hardcoded plan from CVY-008. The state machine keeps working.
